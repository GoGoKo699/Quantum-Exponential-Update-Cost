# Scientific account

The question is whether one normalized exponential update can be produced from independent copies of an unknown state. The account follows the operational task through a response calculation, an indistinguishability proof and constructive comparisons.

1. [Model](model.md): the normalized Esscher target, supplied exact spectrum, unknown orientation, half-trace error and charged copy interface.
2. [Response](response.md): logarithmic means, exact Haar susceptibility, uniform partition-function derivatives and the finite known-observable gap.
3. [Copy converse](copy_lower_bound.md): O'Donnell–Wright's inherited information bound, the two same-spectrum ensembles, the finite-dimensional theorem and heralded/expected-budget extensions.
4. [Filtering baselines](baselines.md): a dimension-independent instrument, all rejected attempts counted, and its commuting coincidence with the target.
5. [Upper bounds](upper_bounds.md): trace-norm stability, spectral repair, collective tomography, an explicit Clifford implementation and final state preparation.
6. [Interpretation](interpretation.md): what the unknown-orientation barrier establishes and which structured-source and implementation questions remain open.

The [related-work ledger](../references/RELATED_WORK.md) separates the Esscher definition, matrix-response calculus, mixedness hardness and generic testing reduction from this task-specific transfer. The [finite verification](../verification/README.md) is a diagnostic complement to the proofs.

The main result concerns identical furnished spectra in dimension divisible by four. A larger numerical constant for a two-spectrum null-versus-contrast comparison is retained as an intermediate proposition in the converse; it is not substituted for the main known-spectrum theorem.
