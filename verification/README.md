# Finite numerical diagnostics

Run from the repository root:

```bash
python -m pip install -r verification/requirements.txt
python verification/checks.py
```

The script writes [results.json](results.json) and [finite_diagnostics.png](finite_diagnostics.png), with a PDF version of the same figure. The result records the random seed, installed library versions, script and dependency-file SHA-256 hashes, and the finite cases checked. The sample cost theorem and dimension-independent derivative bound are analytical statements; this script does not prove them.

The checks use the fixed theorem parameters `a = 0.8`, `h = 0.1`, and half trace output error `0.001`:

- Deterministic qubit integration checks the Haar susceptibility and all second moments used in its derivation. Two Gauss–Legendre orders test numerical convergence; this agreement is not a certified quadrature error bound.
- Seeded Haar draws in dimensions 4, 8, 16, and 32 check the exact finite-dimension susceptibility and second moments. Every response is paired with a conjugate orientation that flips the known tilt, eliminating the initial magnetization and even response terms. Standard errors count each independent pair once.
- The main result's control ensemble has independent balanced Haar involutions within the two known tilt blocks. Its exact supplied spectrum is identical to the full-Haar ensemble, its initial tilt expectation is zero, and its commuting output response is `tanh(h)`. Finite controls check these facts in dimensions 4, 8, 16, and 32.
- Direct eigendecomposition of `log(rho)` is compared with its scalar-shift cancellation, and normalized matrix exponentials are cross-checked against a dense exponential. The input eigenvalues remain positive, their condition number is 9, and the tilt is explicitly a first-qubit Pauli Z.
- A block-exponential evaluation of the first four Duhamel derivatives checks twelve finite instances of the cumulant formula. The analytical constant 26 is recorded; the observed values do not establish a sharper universal constant.
- Constant arithmetic checks the main same-spectrum statement `n > 0.001 D` and the commuting filter's five-attempt failure bound. The original maximally mixed comparator's `0.00769 D` coefficient is recorded separately. A noncommuting qubit is a negative control: its normalized sandwich filter differs from the Esscher target by more than the required error, while the commuting endpoints agree.

Panel A compares full-Haar and block-commuting priors with the same supplied spectrum. It shows finite mean responses with twice the Monte Carlo standard error, alongside the analytical Esscher upper bound; all its dimensions satisfy the main result's divisibility promise. Panel B shows the full-state half trace error of substituting the sandwich filter across qubit orientations, at the same parameters. All plotted data are generated by the script and stored in the result file.

The finite randomized checks are diagnostics of the stated seeded run. They neither certify all dimensions nor supply a priority or implementation-speed claim. The lower bound grants unrestricted known computation and concerns access to copies of the unknown prior.
